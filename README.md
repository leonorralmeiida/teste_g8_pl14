# PES - Depuração

Existe neste repositório um ramo com o seu número de aluno. Nesse ramo encontra um
pequeno programa Java que simula uma bola e que tem **um** erro (ao fazer o *fork*,
garanta que copia todos os ramos e não apenas o `main`). O seu trabalho é:

1. escrever um teste que reproduza o erro;
2. encontrar o erro com o depurador e corrigi-lo;
3. fazer *push* do seu ramo para o seu *fork*;
4. abrir um *Pull Request* para o repositório original, com base no seu ramo.

Requisitos: JDK 17+, Maven 3.8+, git. Não faça *push* para o `main` nem para outros ramos.

Leia com atenção o README do seu ramo: contém o relatório de erro e a especificação.

Antes de começar, garanta que:

1. tem sessão iniciada no GitHub;
2. tem um *Personal Access Token*;
3. configurou o seu nome e email neste computador (pode usar o script `setup.sh`;
   execute-o para ver como se usa).

Para mudar para o seu ramo:

```
git fetch origin
git checkout <o-seu-numero-de-aluno>
```

Bom trabalho!
